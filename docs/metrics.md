# 指标字典

所有指标都基于 DWD 清洗后的行为明细：窗口内（北京时间 2017-11-25 ~ 2017-12-03）、五列完全相同的重复记录只保留一条、主键为空或行为类型非法的记录已剔除。
"活跃"统一指当天有任意一种行为（pv / fav / cart / buy）。

## 流量与行为（`ads_traffic_stats_1d`，粒度：天）

| 指标 | 定义 | 过滤条件 | 来源表 |
|---|---|---|---|
| PV | 当天浏览行为的次数 | behavior_type = 'pv' | dws_user_action_1d.pv_cnt 求和 |
| UV | 当天有浏览行为的去重用户数 | pv_cnt > 0 | dws_user_action_1d |
| 活跃用户数 | 当天有任意行为的去重用户数 | 无 | dws_user_action_1d（一个用户一行） |
| 收藏 / 加购 / 购买次数 | 当天对应行为的次数 | behavior_type = 'fav' / 'cart' / 'buy' | dws_user_action_1d |
| 购买用户数 | 当天有购买的去重用户数 | buy_cnt > 0 | dws_user_action_1d |
| 人均浏览次数 | PV / UV | — | 派生 |
| 购买用户占比 | 购买用户数 / 活跃用户数 | — | 派生 |

## 有序转化漏斗（`ads_conversion_funnel_1d`，粒度：天）

参考常见行为分析工具的"有序漏斗"：在窗口期（当天）内按时间先后完成每一步才算转化。

| 指标 | 定义 | 过滤条件 | 来源表 |
|---|---|---|---|
| 第 1 步 浏览用户数 | 当天有浏览的用户；记首次浏览时间 t1 | behavior_type = 'pv' | dwd_user_behavior_inc |
| 第 2 步 加购/收藏用户数 | t1 之后（含同一秒）有加购或收藏的用户；记满足条件的最早一次为 t2 | behavior_type in ('cart', 'fav') 且 event_ts >= t1 | dwd_user_behavior_inc |
| 第 3 步 购买用户数 | t2 之后（含同一秒）有购买的用户 | behavior_type = 'buy' 且 event_ts >= t2 | dwd_user_behavior_inc |
| 浏览→加购收藏转化率 | 第 2 步 / 第 1 步 | 分母为 0 时为 NULL | 派生 |
| 加购收藏→购买转化率 | 第 3 步 / 第 2 步 | 同上 | 派生 |
| 浏览→购买转化率 | 第 3 步 / 第 1 步 | 同上 | 派生 |

漏斗需要行为的先后顺序，汇总表里只有"首次时间"不够用（用户可能先加购、再浏览、再加购），所以直接读 DWD 明细。
先买后看、只加购没浏览、跨天完成的步骤都不计入当天的后续步骤。

## 留存（`ads_user_retention`，粒度：同期群日期 × 同期群类型 × N）

| 指标 | 定义 | 过滤条件 | 来源表 |
|---|---|---|---|
| 新增用户同期群 | 窗口内首次活跃日期 = cohort_date 的用户 | first_active_date = cohort_date | dws_user_milestone_td |
| 活跃用户同期群 | cohort_date 当天活跃的用户 | — | dws_user_action_1d |
| 第 N 日留存人数 | 同期群里在 cohort_date + N **当天**活跃的人数（不是 N 天内） | N ∈ {1, 3} | dws_user_action_1d |
| 第 N 日留存率 | 留存人数 / 同期群人数 | — | 派生 |

计算日 dt = cohort_date + N：计算日 D 产出 cohort_date = D-1 的次日留存和 cohort_date = D-3 的第 3 日留存，早于数据起始日的同期群不产出。

口径提醒：
- 11-25 是数据第一天，没有更早的历史，所以当天的"新增"就是当天全部活跃用户，新增留存与活跃留存相同。
- 数据集是按用户抽样的：12-02、12-03 两天的活跃用户分别占全部 98.8 万用户的 98.2% 和 97.9%（前 7 天每天只有 71.5%~74.9%），所以观察日落在这两天的留存接近 98%。这反映的是抽样方式，不是真实留存。

## 复购率（`ads_repurchase_rate_td`，粒度：天，截至当天累计）

| 指标 | 定义 | 过滤条件 | 来源表 |
|---|---|---|---|
| 购买用户数 | 从窗口起始日到当天累计购买次数 > 0 的用户数 | cum_buy_cnt > 0 | dws_user_milestone_td |
| 复购率（按天） | 购买天数 >= 2 的用户 / 购买用户数 | buy_days >= 2 | dws_user_milestone_td |
| 复购率（按次数） | 累计购买次数 >= 2 的用户 / 购买用户数 | cum_buy_cnt >= 2 | dws_user_milestone_td |

数据里一次购买一个商品记一行，一单买多件会产生多条 buy 记录，所以"按次数"口径会把"一次买了几件"也算成复购，数值偏高；"按天"口径更接近"回头客"。两个都给出，报表默认用按天口径。

## TopN

| 指标 | 定义 | 过滤条件 | 来源表 → 产出表 |
|---|---|---|---|
| 商品浏览量 Top10 | 当天按浏览次数降序取前 10，浏览次数相同按 item_id 升序 | pv_cnt > 0 | dws_item_action_1d → ads_item_topn_1d |
| 类目购买次数 Top10 | 当天按购买次数降序取前 10，相同按 category_id 升序；附购买用户数、浏览用户数和二者之比 | buy_cnt > 0；类目取行为发生时记录的类目 | dwd_user_behavior_inc → ads_category_topn_1d |

## 连续活跃（`ads_user_continuous_active_7d`，粒度：天）

| 指标 | 定义 | 过滤条件 | 来源表 |
|---|---|---|---|
| 窗口内活跃用户数 | 窗口 [max(D-6, 2017-11-25), D] 内活跃过的用户数 | — | dws_user_action_1d |
| 连续 3 天活跃用户数 | 窗口内存在至少一段连续 >= 3 天都活跃的用户数 | — | dws_user_action_1d |
| 占比 | 连续 3 天活跃用户数 / 窗口内活跃用户数 | — | 派生 |

算法：同一用户的活跃日期按顺序编号 rn，active_date - rn 相同的日期属于同一段连续区间，按 (用户, 区间) 计数。
窗口截断后不足 3 天的连续段不算（例如 11-25 ~ 11-27 连续 3 天的用户，在 12-03 的窗口 11-27 ~ 12-03 里只剩 1 天）。

## 用户等级（`ads_user_level_dist_1d`，粒度：天 × 等级）

| 指标 | 定义 | 过滤条件 | 来源表 |
|---|---|---|---|
| 各等级用户数 | 拉链表中在 D 当天有效（start_date <= D <= end_date）的记录数 | — | dim_user_zip |
| 等级占比 | 各等级用户数 / 当天用户总数 | — | 派生 |

等级规则在码表 `dim_user_level`：按截至当天的累计购买次数，0 次 L0 未购买、1 次 L1 首购、2~4 次 L2 复购、>= 5 次 L3 高频。
档位按全量数据的分布定（四档人数约 32% / 23% / 33% / 12%）。

## 实时指标（Flink SQL，与离线同口径对账）

| 指标 | 定义 | 粒度 | 离线对照 |
|---|---|---|---|
| 分钟 PV | 1 分钟滚动窗口（按事件时间，北京时间对齐）内的浏览次数 | 分钟 | DWD 按 date_format(event_time, 'yyyy-MM-dd HH:mm') 分组计数 |
| 分钟 UV | 同一窗口内有浏览行为的去重用户数 | 分钟 | 同上，count(DISTINCT user_id) |
| 小时商品浏览量 Top10 | 1 小时滚动窗口内按浏览次数降序取前 10，相同按 item_id 升序 | 小时 | DWD 按小时、商品分组后 row_number |
